منصة هاشم TV

HMA Company Trading Ltd
تواصل واتساب

مرحباً بك في وثائق النظام والخدمات الرقمية

هذه الصفحة تعرض الهيكل البرمجي وأوامر التشغيل المحلية الخاصة بمنصة هاشم TV للحلول الإعلانية والتسويق الرقمي.

هيكل المشروع (Project Structure)

  • /index.html الصفحة الرئيسية
  • /dashboard لوحة التحكم التفاعلية
  • /store أصول المتجر الرقمي
  • /server.js خادم Express API

أوامر التشغيل المحلي (Setup)

تشغيل الخلفية (Backend):
npm install
node server.js
تشغيل الواجهة (Frontend):
cd dashboard
npm install && npm run dev
حالة السيرفر المحلي: http://localhost:3000
رابط لوحة Vite: http://localhost:5173
