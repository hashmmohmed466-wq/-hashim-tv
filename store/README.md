# متجر هاشم TV — تعليمات التشغيل

تمت إضافة متجر بسيط على فرع `feature/sales` يعمل مع وسائل دفع يدوية: دفع نقدي عبر واتساب وتحويل بنكي.

ملخص ما تمت إضافته:
- واجهة متجر: `/store/index.html` (RTL) مع عرض منتجات وسلة وطرق checkout.
- بيانات المنتجات: `store/products.json`.
- سكربت خفيف لخادم Node.js: `server.js` مع API:
  - `GET /api/products` — جلب المنتجات
  - `POST /api/orders` — إنشاء طلب وحفظه في `orders.json`, ويرجع رابط واتساب للتأكيد
  - `GET /admin/orders?pass=YOUR_PASS` — جلب قائمة الأوامر (باستخدام كلمة مرور بسيطة)
- صفحة إدارة مبسطة: `/store/admin.html` لعرض الأوامر (تدخل كلمة المرور).

تشغيل محلي (Node.js v16+):
1. في جذر المشروع شغّل:
   ```bash
   npm install
   ```
2. ضع كلمة المرور الإدارية في متغير البيئة `ADMIN_PASS` (افتراضياً `admin123`).
   مثال (bash):
   ```bash
   export ADMIN_PASS=secret123
   ```
3. شغّل الخادم:
   ```bash
   npm start
   ```
4. افتح المتجر في المتصفح:
   - واجهة المتجر: http://localhost:3000/store/
   - لوحة الإدارة: http://localhost:3000/store/admin.html

ملاحظات أمان ووظائف مستقبلية:
- طريقة الحفظ الحالية تحفظ الأوامر في ملف `orders.json` مما يناسب اختبار محلي وMVP؛ للبيئة الحقيقية أفضّل نقل التخزين إلى قاعدة بيانات (Postgres/MySQL) مع حماية أفضل.
- إدارة: حالياً تعتمد كلمة مرور بسيطة في متغير بيئة؛ أنصح بتفعيل مصادقة حقيقية (JWT/Session) وواجهة إدارة مستقرة.
- الدفع: حالياً لا توجد بوابة دفع إلكترونية — الدفع عبر واتساب/تحويل بنكي يدوي. إن رغبت لاحقاً أضيف Stripe أو بوابة محلية.

إذا تريد أتحول للحل بقاعدة بيانات أو أضيف تكامل إشعارات/واتساب تلقائي أو أضيف صفحات تفاصيل المنتج/تصاميم إضافية أخبرني وسأكمل العمل.
